# CodeWhisper PR

## Shared Types

Shared TypeScript types for CodeWhisper PR.

### Installation

```bash
yarn add @codewhisper/shared-types
```

### Usage

```typescript
import { User, Review, TokenUsage } from '@codewhisper/shared-types';
```

### Types Included

- User & Authentication
- Review & PR Data
- Token Usage & Analytics
- API Request/Response Types

### Development

```bash
yarn build    # Build types
yarn type-check  # Check types
```
